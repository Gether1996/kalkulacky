🎯 Ako používať kalkulačku

⌨️ Klávesnica

  • 0-9 - Čísla
  • + - * / - Operácie
  • Enter/= - Výsledok
  • Escape - Vymazať
  • Backspace - Späť
  • % - Percento

🔧 Pokročilé funkcie

  • √ - Druhá odmocnina
  • x² - Druhá mocnina
  • 1/x - Prevrátená hodnota
  • % - Percento z hodnoty
  • ± - Zmena znamienka

💾 Pamäť (Memory)

  • MC - Vymazať pamäť
  • MR - Načítať z pamäte
  • M+ - Pridať do pamäte
  • M- - Odčítať z pamäte

📝 Príklady použitia

  • Zľava 20%: 100 × 20 % = 20
  • Druhá mocnina: 5 × x² = 25
  • Odmocnina: 16 √ = 4
  • Prevrátená: 4 1/x = 0.25
